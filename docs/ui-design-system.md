# Tbox UI 2.0 · Windows / macOS 共用设计规范

状态：2026-11-08 用户确认方案 A「托盘轻面板」，共用桌面工程从 1.1.21 采用此结构；分栏 OCR 沿用 1.1.17 的确认稿。

## 1. 唯一实现与设计边界

Windows 与 macOS 使用同一个 `Tbox.Desktop` 界面工程、布局、图标与状态规则。设计令牌集中在 `src/Tbox.Desktop/Views/DesignTokens.cs`，平台适配层不能另写页面或替换产品配色。允许不同的只有系统字体度量、系统窗口按钮、文件选择器及系统快捷键修饰符。

软件品牌使用用户确认的紫晶工具盒图标：深色底座上的紫色立方体，侧面印白色 T。Windows 与 macOS 共用 `assets/branding/tbox.svg` 及其彩色渲染资源，用于托盘面板、设置窗口、程序图标和安装包。Mac 菜单栏从同一原稿提取立方体轮廓并镂空 T，由系统按当前背景着色。

`src/Tbox.App` 和 `docs/ui-prototypes/` 是上一版 Windows 的行为对照，不代表 UI 2.0 交付；新的 Windows 安装包使用共用界面。

## 2. 信息结构

- 启动后不弹出窗口，只驻留 Windows 托盘或 Mac 菜单栏。单击图标打开托盘面板，右键（Mac 为右键或 Control 单击）保留原生菜单；再次打开应用或从启动台重新打开同样只打开面板。
- 托盘面板宽 360，贴近图标弹出并限制在当前工作区内；失焦、Esc 或开始任何工具时自动收起，截图前先收起，避免拍进面板。
- 面板顶部是品牌、就绪状态和设置齿轮；随后三块主工具：截图（强调色大块，副标题「区域 · 窗口 · 元素」）、贴图、录屏。列表行依次为长截图、识别图片文字（弹出“选择图片… / 识别剪贴板图片”）、显隐全部贴图（显示贴图数量）和文件夹跳转（行内开关）。
- 面板下半部显示最近 4 张截图缩略图，悬停或键盘聚焦时提供“贴到屏幕”和“复制截图”；直接复用缓存文件，不再另存副本。缓存为空时说明截图会出现在这里。底部为版本和退出。
- 缺少屏幕录制权限时，只在尝试截图、长截图或录屏后，于面板顶部显示一次就地授权条；仅点击“去授权”才向系统申请。
- 设置是独立窗口，用「常规 / 文件夹跳转」分段标签切换，集中外观、启动、通知、工具开关、快捷键诊断、缓存、更新和反馈；不再承载截图、贴图、OCR 等日常工具。没有窗口打开时的操作反馈以 4 秒提示显示。
- 截图的全局快捷键显示 Windows 的 F6 或 macOS 的 ⌃⇧1，其他工具按平台实际注册的按键标识。

## 3. 颜色

采用清爽中性底色、白色/深色表面和取自应用图标的紫晶交互色。浅深主题共享角色与层次，平台之间不分叉。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F6F6F9` | `#131318` |
| 主表面 | `#FFFFFF` | `#1D1D24` |
| 次表面 | `#F1F1F6` | `#18181E` |
| 悬停 | `#EBEBF2` | `#2A2A33` |
| 边框 | `#E3E3EC` | `#30303A` |
| 主要文字 | `#17181F` | `#F2F2F6` |
| 辅助文字 | `#5E6270` | `#A6A9B6` |
| 交互强调色 | `#6D4AE8` | `#B4A0FF` |
| 强调底色 | `#F0ECFF` | `#2C2645` |
| 提醒 | `#9A6A12` | `#F2B65A` |

托盘面板的截图主块在两种主题下都填充品牌紫晶 `#6D4AE8` 并使用白字；深色强调色只用于文字、开关和链接。

截图蓝、长截图黄、录屏红、成功绿只表示模式或状态，选区边框按所选模式着色；所有状态同时提供文字或图标。任务浮层固定深色 `#20242D`，边框 `#4B5363`，避免桌面背景影响可读性。

## 4. 字体、间距与形状

只有四级文本层级：页面标题 `28 / 36`、分区标题 `16 / 24`、正文 `14 / 20`、辅助说明 `12 / 16`。标题使用半粗字重；不用放大字号代替信息层次。

使用 `4 / 8 / 12 / 16 / 24 / 32` 间距序列。页面按窗口宽度使用 32、24 或 16 的内容边距。卡片圆角 12，托盘面板圆角 14，普通控件圆角 8，任务浮层圆角 8；普通按钮最小高度 36。卡片使用细边框，避免多层卡片嵌套与强阴影。

快捷操作图标为 20×20 线性矢量图。主操作使用强调底色，快捷键置于按钮右侧。

## 5. 布局与交互

设置窗口默认 560×520，打开时按工作区限制尺寸。设置页正文最大宽度为 560，只允许纵向滚动。托盘面板固定宽 360，高度随内容。设置行空间不足时将控件移到标题下方。

同一控件的默认、悬停、按下、选中、禁用和焦点状态必须保持尺寸稳定。滑动开关显示真实设置或系统状态；待系统批准不伪装为已开启，并提供取消申请。设置写入串行且原子完成，连续修改不同设置不能互相覆盖。

## 6. 结果与任务浮层

OCR 使用主题化编辑工作区。宽度至少 720 时默认显示左侧原图和右侧编辑器。窄窗口默认隐藏原图，可在编辑器上方展开。原图收起后，编辑器填充剩余工作区。窗口动作在上方，复制与识别反馈在下方。图片画布和录屏回放保留中性深色底，外围控件复用令牌。

截图与贴图共享一个标注工具条；长截图和录屏复用同一深色表面、边框、状态规则和图标度量。紧凑工具条保持 `30×32` 按钮与 20×20 图标盒，功能顺序、缩放及末端按钮完整性不能因视觉重构回退。

## 7. 验收

共用控件渲染预览见[托盘面板](ui-prototypes/screenshots/shared-tray-panel.png)、[设置窗口](ui-prototypes/screenshots/shared-compact-panel.png)和[OCR 工作区](ui-prototypes/screenshots/shared-ocr-workspace.png)。OCR 图使用测试文档和识别结果。

- 两平台必须构建并实际运行同一界面代码；系统窗口装饰不同不算设计分叉。
- 界面没有搜索。托盘面板测试覆盖浅深主题、全部工具入口、按钮不越界、模块关闭、失焦与 Esc 收起、最近截图排序与复用缓存、空缓存说明及贴近图标定位；设置窗口布局测试覆盖浅色、深色和 1280、900、560、360 宽度。OCR 验收覆盖宽窄重排、显隐原图、保留编辑文本和复用原图。
- 正文及辅助文字对背景满足 WCAG AA，关键图标至少 3:1。纯图标控件提供提示与可访问名称，键盘焦点顺序与视觉顺序相同。
- 生成真实共用控件渲染预览；不能把历史 HTML 原型或只通过编译视为新设计验收。
- 截图、贴图、OCR、长截图和录屏的原有交互、像素及安全关闭规则保持有效，分别复验。
