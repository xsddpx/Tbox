# Tbox UI 1.0 统一界面规范

> 状态：已确认并经真实窗口复验完成 WinUI 落地（v1.0.41）
>
> 确认日期：2026-07-16（Asia/Shanghai）
>
> 适用范围：设置、主页、工具配置、截图与贴图、长截图、区域录屏、文字识别及结果预览

## 1. 设计目标

Tbox 采用 Windows 11 Fluent 的控件语言和 PowerToys 式信息架构，形成中性暖灰、紧凑克制、功能优先的桌面工具体验。

统一不等于所有界面使用相同背景。产品按工作环境分为两类表面：

- **管理与结果界面**：设置、主页、工具配置、文字识别、长截图结果和录屏回放跟随用户选择的浅色、深色或系统主题。
- **任务浮层**：截图、贴图、长截图和录屏控制条固定使用高对比深色，确保在任意桌面内容上清晰可见。

两类表面共享字体、间距、圆角、图标、状态、文案和无障碍规则。

## 2. 设计原则

1. **内容优先**：截图和媒体内容始终是视觉主体，工具条不抢占、不遮挡结果。
2. **语义一致**：同一动作在不同场景使用相同名称、图标、顺序和反馈。
3. **紧凑但可读**：管理界面使用常规密度，任务工具条使用桌面精确操作所需的紧凑密度。
4. **状态稳定**：悬停、按下、选中和刷新不得造成控件位移、闪烁或尺寸变化。
5. **跨平台可迁移**：颜色和控件实现可以适配目标平台，但信息层级、场景分类和可观察交互保持一致。

## 3. 基础令牌

### 3.1 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `Background` | `#F4F1EE` | `#202020` | 页面和应用背景 |
| `SurfacePrimary` | `#FFFEFC` | `#292929` | 卡片、工作区、一级表面 |
| `SurfaceSecondary` | `#F7F4F1` | `#323232` | 标题栏、次级区域、控件表面 |
| `SurfaceHover` | `#EAE7E4` | `#3A3A3A` | 中性悬停 |
| `BorderDefault` | `#DED9D4` | `#414141` | 卡片和控件边框 |
| `BorderSubtle` | `#E9E4DF` | `#363636` | 分隔线 |
| `TextPrimary` | `#202020` | `#F5F5F5` | 标题、正文、主要控件文字 |
| `TextSecondary` | `#625E5A` | `#C2C2C2` | 说明、状态、次要信息 |
| `TextDisabled` | `#9A9692` | `#777777` | 禁用内容 |
| `Accent` | 平台系统强调色 | 平台系统强调色 | 选择、焦点、主操作 |

模式状态色固定为：

- 截图蓝 `#0078D4`
- 长截图黄 `#FFCC00`
- 录屏红 `#FF3B30`
- 成功与长截图视口绿 `#34C759`

模式色只表示工作模式或状态，不替代文字、图标和可访问名称。普通按钮不得使用模式色装饰。

### 3.2 字体

Windows 当前使用 `Segoe UI Variable`，其他平台使用其系统界面字体。只保留四级信息层级：

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | `28 / 36` | Semibold | 页面主标题 |
| 分区标题 | `16 / 24` | Semibold | 分区、卡片、窗口内一级标题 |
| 正文与控件 | `14 / 20` | Regular；强调时 Semibold | 正文、导航、按钮、表单 |
| 辅助说明 | `12 / 16` | Regular | 快捷键、状态、补充说明 |

数据、尺寸和计时使用等宽数字特性；不新增仅用于视觉微调的零散文本字号。图标字号不属于文本层级。

### 3.3 间距与尺寸

- 基础间距：`4 / 8 / 12 / 16 / 24 / 32`
- 页面内容边距：宽屏 `32`，中等宽度 `24`，窄屏 `16`
- 卡片间距：`12` 或 `16`
- 普通控件高度：`32`
- 主要操作按钮高度：`36–40`
- 设置行最小高度：`64`；包含两行说明时建议 `72`
- 普通页面最小交互目标：`40×40`；紧凑任务工具条例外为 `30×32`

### 3.4 圆角、边框与阴影

- 卡片、浮层、菜单：`8`
- 普通按钮和输入控件：`4–6`
- 工具条：`8`
- 胶囊状态：高度的一半
- 卡片主要使用 `1` 像素边框，不堆叠阴影
- 阴影只用于独立窗口、浮层、菜单和任务工具条

## 4. 布局规范

### 4.1 设置与主页

- 标题栏高度 `52`，导航宽度 `240`，页面内容最大宽度 `1120`。
- `≥1080` 显示固定侧栏；`720–1079` 使用汉堡按钮控制的浮层侧栏；`<720` 使用单列内容。
- 侧栏导航区可独立纵向滚动，底部辅助入口固定可见。
- 页面只允许纵向滚动，不得出现横向滚动条或被窗口裁切。
- 窄屏设置行将说明和控件上下排列，主要控件拉伸至可用宽度。

### 4.2 结果工作区

- 文字识别、长截图结果和录屏回放使用普通独立窗口，跟随主题。
- 图片或视频画布可以保持黑色或中性深色，工具区仍使用统一主题令牌。
- 标题栏放置窗口级动作；内容动作放在底部操作区，不在多个位置重复。
- 处理中、成功和失败在当前窗口就地显示，通知只作为补充。

## 5. 任务工具条

### 5.1 基础结构

- 容器固定深色：背景约 `#202020`，边框 `#707070`，圆角 `8`，内边距 `4`。
- 按钮 `30×32`，按钮间距 `2`，图标盒 `20×20`。
- 普通符号光学尺寸约 `17`，Fluent 图标约 `14–16`；按图形面积校准，不按字体字号机械统一。
- 分隔线 `1×22`，两侧保留 `4` 间距。
- 尺寸、帧率和计时等少量数据可以使用正文或辅助字号，不增加大块状态说明。

### 5.2 场景规则

- 截图与贴图共享标注按钮顺序、图标和状态；末端动作按场景替换。
- 长截图控制条复用同一容器、按钮和状态，只显示实时尺寸、贴图、保存、全屏、取消和复制。
- 录屏控制条复用同一容器和按钮状态，模式色仅用于录制状态和选区边框。
- 所有工具条必须按所在显示区域的有效缩放计算完整尺寸，不得裁切末端按钮或出现滚动条。

## 6. 控件状态与动效

所有可交互控件必须定义：默认、悬停、按下、选中、禁用和键盘焦点。

- 状态切换只改变颜色、边框或轻微透明度，不改变控件占位尺寸。
- 普通过渡时长 `120–160ms`，侧栏和浮层 `180ms`。
- 不使用弹跳、大幅缩放或无功能意义的循环动画。
- 系统关闭动画或启用减少动态效果时，应取消非必要过渡。
- 刷新状态时不得重复替换当前视觉资源并重新启动过渡。

## 7. 图标与文案

- 优先使用平台原生 Fluent 图标；没有合适图标时使用项目自有、风格一致的矢量图标。
- 同一动作必须复用同一图标，不得因窗口不同而重新解释。
- 纯图标按钮必须提供 Tooltip 和可访问名称。
- 中文按钮使用简短动宾结构，例如“复制全部”“重新录制”“另存为…”。
- 只有会继续打开选择器、对话框或下一步配置的动作使用省略号。
- 错误提示说明发生了什么以及用户可以做什么，避免只显示错误码。

## 8. 无障碍与验收

- 正文和关键图标与背景的对比度至少达到 WCAG AA；非文字模式边框不承担唯一信息表达。
- 键盘焦点清晰可见，顺序与视觉顺序一致；对话框有明确的默认与取消动作。
- 缩放后文本不得被截断，工具条不得出现横向滚动。
- 图标按钮必须通过可访问名称被辅助技术识别。
- 界面在浅色、深色、100%、125%、150% 缩放和窄屏状态下均应验证。
- 悬停、连续状态刷新和窗口尺寸变化不得产生闪烁或布局跳动。
