# Tbox UI 3.0 · Windows / macOS 共用设计规范

状态：2026-11-09 用户确认 UI 3.0 规范（基础、控件、主窗口、结果窗口、任务浮层五张规范板）。它取代 1.1.21 的托盘轻面板和 1.1.22 的独立设置窗口：所有日常工具和设置合并为一个带侧栏的主窗口。分栏 OCR 沿用 1.1.17 的确认稿，只调整外框。

规范板渲染图：[基础](images/ui-3.0-1-foundations.jpg)、[控件](images/ui-3.0-2-components.jpg)、[主窗口](images/ui-3.0-3-main.jpg)、[结果窗口](images/ui-3.0-4-results.jpg)、[任务浮层](images/ui-3.0-5-tasks.jpg)。

## 1. 唯一实现与设计边界

所有交互、布局和内容方案优先参考 PixPin、Listary 已有的成熟设计，入口与使用原则见 [产品设计参考](product-references.md)。采用时保持本规范的统一视觉；如需改变已确认的产品行为，先按产品需求变更流程处理。

Windows 与 macOS 使用同一个 `Tbox.Desktop` 界面工程、布局、图标与状态规则。设计令牌集中在 `src/Tbox.Desktop/Views/DesignTokens.cs`，共用控件在 `Ui.cs`，平台适配层不能另写页面或替换产品配色。允许不同的只有系统字体度量、系统窗口按钮、文件选择器及系统快捷键修饰符。

软件品牌使用紫晶工具盒图标：深色底座上的紫色立方体，侧面印白色 T。Windows 与 macOS 共用 `assets/branding/tbox.svg` 及其彩色渲染资源，用于主窗口、结果窗口、程序图标和安装包。Mac 菜单栏从同一原稿提取立方体轮廓并镂空 T，由系统按当前背景着色。

## 2. 信息结构

- 启动后不弹出窗口，只驻留 Windows 托盘或 Mac 菜单栏。单击图标打开主窗口；右键保留原生菜单（打开 Tbox、退出）。关闭主窗口只是隐藏，快捷键照常可用；只有菜单里的“退出”结束应用。
- 主窗口默认 800×600，最小 680×520，打开时限制在工作区 90% 以内。左侧 208 宽侧栏分“工具”和“设置”两组：截图、文件夹跳转、通用、关于；底部显示版本号。以后新增的工具加在“工具”组内。右侧是一张白色内容卡。
- 隐藏后重新打开回到“截图”页；窗口已打开时保持当前页。
- 侧栏圆点：红点表示该页有错误（如快捷键冲突），黄点表示需要授权或有可用更新。
- 工具页结构相同：页头（柔色工具图标、标题、说明，右侧为模块开关）→ 可选提示条 → 横幅（主入口）→ 设置分组。模块关闭时显示灰色说明并禁用工具入口，快捷键同时释放。
- 截图页横幅放大主按钮“截图”（附当前截图快捷键键帽），下面是贴出剪贴板、长截图、录屏、识别文字四个次级入口，再往下是最近 4 张截图（16:9 缩略图，单击打开图片预览，悬停可贴图或复制）和截图设置（快捷键录制器、保存位置）。缓存为空时说明截图会出现在这里。
- 缺少屏幕录制权限时，只在尝试截图、长截图或录屏后显示授权提示条；此时提示条的“去授权”是本页唯一主按钮，横幅按钮降为次按钮。打开窗口本身从不请求权限。
- 通用页集中开机启动、失败提示和反馈；关于页显示版本、检查更新、下载进度与安装。
- 具备截图权限时，普通截图的按钮、全局快捷键和菜单入口都保留主窗口的显示状态，已显示的主窗口可以截入画面。单独启动长截图或录屏时，主窗口先隐藏，取消选区后重新显示原本打开的主窗口。

## 3. 颜色

只有浅色主题，不再提供主题切换。

| 角色 | 值 |
| --- | --- |
| 窗口底（侧栏） | `#F4F3F8` |
| 内容卡 | `#FFFFFF` |
| 主要文字 | `#1A1B22` |
| 辅助文字 | `#5F6270` |
| 分组标题 | `#8C8F9B` |
| 行分隔线 | `#F1F0F5` |
| 交互强调色（紫晶） | `#6D4AE8`，悬停 `#5E3DD8`，按下 `#5232C4` |
| 错误 | `#D9363E` |
| 提醒（文字 / 圆点） | `#B7791F` / `#E8A13A` |

每个窗口最多一个紫晶实心按钮，放当前主要步骤；其余用白底细描边的次按钮或文字链接。危险操作只在确认框里用红色。工具图标使用柔色底块（截图紫、文件夹跳转琥珀、识别绿、录屏红等），只区分工具，不表示状态。

任务浮层固定深色：底 `#1D1D24`，边框 `#3A3A46`，悬停 `#2E2E39`，文字 `#F2F2F6`，次要文字 `#A6A9B6`。选区颜色表示模式：截图蓝 `#3D7BFF`、长截图黄 `#E8A13A`、录屏红 `#E5484D`。

## 4. 字体、间距与形状

页面标题 20，分区标题 16，正文 14，说明 12.5，标注 12；标题半粗。使用 `4 / 8 / 12 / 16 / 24 / 32` 间距。内容卡与提示卡圆角 14，卡片 12，控件 8，任务浮层 10。按钮高 32，大主按钮 36。设置行高 52（无说明 46），名称 14、说明 12，控件靠右。内容卡里不再套卡片：分组 = 灰色小标题 + 若干行，行间 1 px 分隔线。

所有图标为 24 单位网格、1.7 线宽、圆角端点的线性矢量图，集中在 `LineIcon`；页面图标 18–20，工具条图标 18。界面不使用 Unicode 字符充当图标。快捷键一律用键帽显示，组合键每个键一个帽。

## 5. 控件

- 开关只用于立即生效的设置；2–4 个互斥选项用分段（如录屏格式 MP4 / GIF / WebP）；更多选项用下拉。
- 横幅：淡紫渐变，圆角 14，每页最多一个。提示条：黄色浅底，可带一个主按钮，按严重程度一次只显示一条。说明：灰底，不可操作。
- 悬停提示写“名称 · 快捷键”。状态为圆点加文字。进度条高 6、圆角 3。
- 同一控件在默认、悬停、按下、选中、禁用和焦点状态下尺寸不变。开关显示真实设置或系统状态；待系统批准时不伪装为已开启，并提供取消申请。

## 6. 结果窗口与提示

OCR、图片预览和录屏预览与主窗口同结构：浅紫灰窗口底 → 页头（柔色工具图标 + 标题 + 说明 + 右侧次要操作）→ 内容 → 底部操作栏（左状态、右按钮，主按钮在最右）。

- 文字识别：宽度至少 720 时左原图（深色画布）右编辑器；更窄时原图默认收起。空结果显示灰色图标、原因和下一步，“复制全部”不可用。
- 图片预览：棋盘格画布；去掉“关闭”按钮，用窗口关闭；“复制”为主按钮。
- 录屏预览：外框浅色，只有视频画布保持深色；进度条用录屏红；格式用分段选择。
- 确认框：标题是问题，说明讲后果；左“返回”、右为动作本身，删除类用红色，Esc = 返回。
- 角落提示只在主窗口未打开时出现：成功 4 秒消失；失败停留到关闭，并提供“打开 Tbox”。

## 7. 任务浮层与工具条

所有任务共用一种工具条：深色底、圆角 10、按钮 30×32、图标 18，分组之间 1 px 竖线，不加文字。工具条里需要文字的只有尺寸、计时、帧率和“开始录制”。

- 截图、长截图和录屏选区的顶部提示条在各显示器内居中，位于该显示器顶部安全区下方并留出 18 点间距。
- 截图：顶部提示条“拖动框选，单击选窗口”加 `R` 上次区域、`Tab` 元素检测、`Esc` 取消键帽。选区上方的尺寸标签用模式色。工具条分两行，与选区左对齐：第 1 行为矩形、椭圆、箭头、直线、画笔、高亮、马赛克、文字、序号、橡皮擦 | 颜色、减小粗细、增大粗细 | 撤销、重做；第 2 行为长截图、录屏 | 贴图、识别文字、保存、复制 | 取消。
- 选中的标注工具紫晶填充、白色图标；再次点击取消选中。不可撤销 / 重做时降为 35% 不透明度。颜色弹层是同一深色表面，色板为 `#E5484D #F5B400 #1F9D61 #3D7BFF #6D4AE8 #1A1B22 #FFFFFF`，默认红色。
- 贴图单击选中后显示紫晶细边框。按空格才展开工具条，再按空格、Enter 或点击完成收起。第一排与截图共享完整标注工具、颜色粗细和撤销重做，第二排为识别文字、保存、复制及完成。
- 长截图：黄色选区（无控制柄），右侧实时预览显示“已拼接 N 屏 · 继续滚动”；工具条为尺寸 | 贴图、全屏预览、保存、复制 | 取消。
- 录屏：准备条为帧率（分段 5/10/15/25/60）| 系统声音 | 红色“开始录制”、取消；录制中只留计时（红点，暂停时变灰）| 暂停、停止 | 取消，选区变为虚线表示不可再调整。
- 位置：工具条贴在选区下方 12 px；空间不够移到上方，再不够放进选区内底部。
- 完成类操作按 Enter 触发（截图、长截图为复制，录屏为开始 / 停止，贴图为完成）；取消固定在最右，按 Esc 触发。
- 录屏只在“开始录制”和录制圆点使用红色；长截图只在选区和尺寸标签使用黄色。

## 8. 验收

- 两平台必须构建并实际运行同一界面代码；系统窗口装饰不同不算设计分叉。
- 主窗口测试覆盖四页切换、全部工具入口、模块关闭说明、关闭只隐藏、重新打开回到截图页、权限提示条为唯一主按钮及侧栏圆点、最近截图排序与复用缓存、空缓存说明，并在 680 / 800 / 1280 宽度下检查布局。
- 统一设计测试覆盖结果窗口与对话框的页头、操作栏主按钮在最右、每窗至多一个主按钮、确认框按钮顺序、角落提示样式及无字符图标。
- 任务工具条测试覆盖截图两行的按钮顺序与分隔线、悬停提示格式、选中填充与再次点击取消、规范色板、录屏 / 长截图确认只用图标、贴图仅在选中后按空格展开以及与截图共享完整标注工具、录屏准备与录制两种状态和虚线选区、模式色，以及工具条位置规则。
- 正文及辅助文字对背景满足 WCAG AA，关键图标至少 3:1。纯图标控件提供提示与可访问名称，键盘焦点顺序与视觉顺序相同。
- 设置 `TBOX_UI_PREVIEWS=<目录>` 运行桌面测试会输出真实控件渲染预览；不能把 HTML 规范板或只通过编译视为验收。
- 截图、贴图、OCR、长截图和录屏的原有交互、像素及安全关闭规则保持有效，分别复验。
