# Tbox UI 2.0 · Windows / macOS 共用设计规范

状态：2026-11-08 用户确认轻量面板和分栏 OCR，共用桌面工程从 1.1.17 采用此结构。

## 1. 唯一实现与设计边界

Windows 与 macOS 使用同一个 `Tbox.Desktop` 界面工程、布局、图标与状态规则。设计令牌集中在 `src/Tbox.Desktop/Views/DesignTokens.cs`，平台适配层不能另写页面或替换产品配色。允许不同的只有系统字体度量、系统窗口按钮、文件选择器及系统快捷键修饰符。

软件品牌使用用户确认的紫晶 T 图标。Windows 与 macOS 共用 `assets/branding/tbox.svg` 及其彩色渲染资源，用于主面板、程序图标和安装包。Mac 菜单栏从同一原稿提取 T 形轮廓，由系统按当前背景着色。

`src/Tbox.App` 和 `docs/ui-prototypes/` 是上一版 Windows 的行为对照，不代表 UI 2.0 交付；新的 Windows 安装包使用共用界面。

## 2. 信息结构

- 主窗口沿用系统标题栏，内容区顶部保留品牌标识、返回和设置入口。
- 主面板用单列按钮突出截图，随后是剪贴板贴图、文字识别、文件夹跳转，以及显隐贴图和区域录屏。
- OCR 启动页提供图片文件与剪贴板图片。目录跳转页显示当前目录、工具开关及必要权限。
- 设置页集中外观、启动、通知、工具、缓存、更新和反馈。权限及操作反馈按任务显示。
- 截图的全局快捷键显示 Windows 的 F6 或 macOS 的 ⌃⇧1，其他工具按平台实际注册的按键标识。

## 3. 颜色

采用清爽中性底色、白色/深色表面和靛蓝交互色。浅深主题共享角色与层次，平台之间不分叉。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F5F7FA` | `#15181E` |
| 主表面 | `#FFFFFF` | `#20242D` |
| 次表面 | `#EEF1F6` | `#1A1E26` |
| 悬停 | `#E7ECF4` | `#303746` |
| 边框 | `#DFE5EF` | `#394252` |
| 主要文字 | `#202838` | `#F0F3F8` |
| 辅助文字 | `#5E6A7D` | `#AFB8C8` |
| 交互强调色 | `#5265DB` | `#A5B2FF` |
| 强调底色 | `#EDF0FF` | `#2B3455` |

截图蓝、长截图黄、录屏红、成功绿只表示模式或状态；所有状态同时提供文字或图标。任务浮层固定深色 `#20242D`，边框 `#4B5363`，避免桌面背景影响可读性。

## 4. 字体、间距与形状

只有四级文本层级：页面标题 `28 / 36`、分区标题 `16 / 24`、正文 `14 / 20`、辅助说明 `12 / 16`。标题使用半粗字重；不用放大字号代替信息层次。

使用 `4 / 8 / 12 / 16 / 24 / 32` 间距序列。页面按窗口宽度使用 32、24 或 16 的内容边距。卡片圆角 12，普通控件圆角 8，任务浮层圆角 8；普通按钮最小高度 36。卡片使用细边框，避免多层卡片嵌套与强阴影。

快捷操作图标为 20×20 线性矢量图。主操作使用强调底色，快捷键置于按钮右侧。

## 5. 布局与交互

主窗口默认 560×460，启动时按工作区限制尺寸。主面板和设置页正文最大宽度为 560，只允许纵向滚动。设置行空间不足时将控件移到标题下方。

同一控件的默认、悬停、按下、选中、禁用和焦点状态必须保持尺寸稳定。滑动开关显示真实设置或系统状态；待系统批准不伪装为已开启，并提供取消申请。设置写入串行且原子完成，连续修改不同设置不能互相覆盖。

## 6. 结果与任务浮层

OCR 使用主题化编辑工作区。宽度至少 720 时默认显示左侧原图和右侧编辑器。窄窗口默认隐藏原图，可在编辑器上方展开。原图收起后，编辑器填充剩余工作区。窗口动作在上方，复制与识别反馈在下方。图片画布和录屏回放保留中性深色底，外围控件复用令牌。

截图与贴图共享一个标注工具条；长截图和录屏复用同一深色表面、边框、状态规则和图标度量。紧凑工具条保持 `30×32` 按钮与 20×20 图标盒，功能顺序、缩放及末端按钮完整性不能因视觉重构回退。

## 7. 验收

共用控件渲染预览见[主面板](ui-prototypes/screenshots/shared-compact-panel.png)和[OCR 工作区](ui-prototypes/screenshots/shared-ocr-workspace.png)。OCR 图使用测试文档和识别结果。

- 两平台必须构建并实际运行同一界面代码；系统窗口装饰不同不算设计分叉。
- 界面没有搜索。轻量面板布局测试覆盖浅色、深色和 1280、900、560、360 宽度。OCR 验收覆盖宽窄重排、显隐原图、保留编辑文本和复用原图。
- 正文及辅助文字对背景满足 WCAG AA，关键图标至少 3:1。纯图标控件提供提示与可访问名称，键盘焦点顺序与视觉顺序相同。
- 生成真实共用控件渲染预览；不能把历史 HTML 原型或只通过编译视为新设计验收。
- 截图、贴图、OCR、长截图和录屏的原有交互、像素及安全关闭规则保持有效，分别复验。
