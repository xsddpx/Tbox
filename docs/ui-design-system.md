# Tbox UI 2.0 · Windows / macOS 共用设计规范

状态：2026-11-07 已应用于共用桌面工程，Mac 1.1.5 已安装；浅深布局测试与 Mac 导航/OCR 复验通过，Windows 实机与全部任务浮层仍待验收。用户明确要求两平台使用相同设计规范、界面更现代、移除搜索。

## 1. 唯一实现与设计边界

Windows 与 macOS 使用同一个 `Tbox.Desktop` 界面工程、布局、图标与状态规则。设计令牌集中在 `src/Tbox.Desktop/Views/DesignTokens.cs`，平台适配层不能另写页面或替换产品配色。允许不同的只有系统字体度量、系统窗口按钮、文件选择器及系统快捷键修饰符。

`src/Tbox.App` 和 `docs/ui-prototypes/` 是上一版 Windows 的行为对照，不代表 UI 2.0 交付；新的 Windows 安装包必须使用共用界面。旧版原型中的搜索、PowerToys 外观和暖灰配色已被本规范取代。

## 2. 信息结构

- 标题区仅保留窗口控制、应用标识和必要导航；移除搜索框、搜索快捷键、隐藏搜索入口及搜索路由。
- 侧栏只有主页、常规、文件夹跳转、截图与贴图四个入口。采用相同线性图标，不按操作系统切换图标风格。
- 主页以三张操作卡片提供截图、剪贴板贴图和文件夹跳转；工具状态与开关随后显示。
- 常规页承载版本、主题、开机启动、失败通知及快捷键。主题只在这里设置，不增加主题按钮或强调色选项。
- 工具页集中呈现配置和可用操作；状态就地反馈，不通过重复弹窗解释权限。
- 底部欢迎、新增内容和反馈入口独立于可滚动导航区。

## 3. 颜色

采用清爽中性底色、白色/深色表面和靛蓝交互色。浅深主题共享角色与层次，平台之间不分叉。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F5F7FA` | `#15181E` |
| 主表面 | `#FFFFFF` | `#20242D` |
| 侧栏/次表面 | `#EEF1F6` | `#1A1E26` |
| 悬停 | `#E7ECF4` | `#303746` |
| 边框 | `#DFE5EF` | `#394252` |
| 主要文字 | `#202838` | `#F0F3F8` |
| 辅助文字 | `#5E6A7D` | `#AFB8C8` |
| 交互强调色 | `#5265DB` | `#A5B2FF` |
| 强调底色 | `#EDF0FF` | `#2B3455` |

截图蓝、长截图黄、录屏红、成功绿只表示模式或状态；所有状态同时提供文字或图标。任务浮层固定深色 `#20242D`，边框 `#4B5363`，避免桌面背景影响可读性。

## 4. 字体、间距与形状

只有四级文本层级：页面标题 `28 / 36`、分区标题 `16 / 24`、正文 `14 / 20`、辅助说明 `12 / 16`。标题使用半粗字重；不用放大字号代替信息层次。

使用 `4 / 8 / 12 / 16 / 24 / 32` 间距序列。页面按窗口宽度使用 32、24 或 16 的内容边距。卡片圆角 12，普通控件圆角 8，任务浮层圆角 8；普通按钮最小高度 36。卡片使用细边框，避免多层卡片嵌套与强阴影。

快捷操作图标为 20×20 线性矢量图，置于 40×40 的浅强调色底板；快捷键使用辅助文字，与操作名称分开。

## 5. 布局与交互

侧栏宽 224；窗口宽度至少 1080 时固定显示，较小时由汉堡按钮打开浮层侧栏。720 以下操作卡片和设置行改为单列。页面内容最大宽度 1120，只允许纵向滚动，不出现横向越界。

同一控件的默认、悬停、按下、选中、禁用和焦点状态必须保持尺寸稳定。滑动开关显示真实设置或系统状态；待系统批准不伪装为已开启，并提供取消申请。设置写入串行且原子完成，连续修改不同设置不能互相覆盖。

## 6. 结果与任务浮层

OCR 使用主题化编辑工作区，标题与原图/置顶等窗口动作位于上方，复制与结果状态位于底部。图片画布和录屏回放保留中性深色底，外围控件复用令牌。

截图与贴图共享一个标注工具条；长截图和录屏复用同一深色表面、边框、状态规则和图标度量。紧凑工具条保持 `30×32` 按钮与 20×20 图标盒，功能顺序、缩放及末端按钮完整性不能因视觉重构回退。

## 7. 验收

- 两平台必须构建并实际运行同一界面代码；系统窗口装饰不同不算设计分叉。
- 所有页面不再出现搜索。测试必须覆盖浅色/深色及 1280、900、520 宽度，并反复切换侧栏模式。
- 正文及辅助文字对背景满足 WCAG AA，关键图标至少 3:1。纯图标控件提供提示与可访问名称，键盘焦点顺序与视觉顺序相同。
- 生成真实共用控件渲染预览；不能把历史 HTML 原型或只通过编译视为新设计验收。
- 截图、贴图、OCR、长截图和录屏的原有交互、像素及安全关闭规则保持有效，分别复验。
