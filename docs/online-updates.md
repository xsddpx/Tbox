# 在线更新

## 下载渠道

用户已将下载权限改为公开。安装包使用独立的公开仓库 [xsddpx/Tbox-releases](https://github.com/xsddpx/Tbox-releases/releases)，现有 `xsddpx/Tbox` 源码仓库保持私有。客户端没有 GitHub 登录流程，不读取或保存账号令牌，不申请钥匙串权限。

[1.1.15](https://github.com/xsddpx/Tbox-releases/releases/tag/v1.1.15) 已正式公开。Windows 和 Mac 安装包均已匿名完整下载并校验大小及 SHA-256；Mac 包还通过与当前安装版相同的签名要求。公开渠道验证不等于应用内升级完成：本机仍是 1.1.13 且已锁屏，需用户解锁后继续真实检查、下载、安装、重启及权限验收。

## 客户端流程

在“常规 → 检查更新”打开共用更新窗口，手动检查、阅读说明、下载和确认安装。未自动后台检查或静默安装。现有 Windows 1.0.45 和 Mac 1.1.6 及以前版本没有此入口，需要先手动升级到包含更新器的版本。

1. 匿名读取公开 Releases，选择最新 100 个记录中高于当前版本的最高正式版本；跳过草稿、预发布和不符合版本格式的标签。
2. 要求当前平台安装包已上传且具有有效的大小与 SHA-256。最新版本未准备当前平台资产时提示稍后检查，不默默改用更早版本。
3. 下载进度可取消，下载未完成时仅生成随机名称的 `.partial` 文件；失败或取消会清理。检查请求最长 30 秒，下载最长 15 分钟。HTTPS 跳转仅允许 GitHub 的两个资产域名，全部请求不携带 Authorization。
4. 下载内容再次核对后才允许安装；校验失败保持旧版本。截图、录屏、贴图或结果窗口尚未结束时拒绝重启。
5. macOS 解包前检查路径、符号链接和体积；新应用必须通过深度签名验证并满足当前应用的指定签名要求，Bundle ID 与版本必须正确。只覆盖 `/Applications/Tbox.app` 或 `~/Applications/Tbox.app`，沿用路径与持久签名。
6. Mac 准备目录与目标位于同一文件系统，应用退出后才替换。保留 `.tbox-update-*/Previous.app` 和 `install.log`；替换失败或启动命令返回失败会恢复旧包。它不监控新进程健康，不能保证启动后崩溃自动回滚。
7. Windows 要求已安装 MSIX 身份，清单与现有 Name、Publisher、App ID、架构及新版本一致。打开系统 App Installer，由系统校验受信任签名并确认、事务安装；完成后重新打开 Tbox。系统安装程序无法启动时就地提示，不退出应用。

关闭更新窗口会取消下载并清理本轮缓存；已交给系统安装程序的文件保留，以免在安装完成前删除。Mac 安装恢复副本目前需手动清理；这是有意保留的恢复材料，不属于截图缓存。

## 发布约定

- 正式标签为 `v<主版本>.<次版本>.<补丁>`，更新器不提供降级或同版本重装。
- Mac 资产为 `Tbox_<三段版本>_osx-arm64.zip`；Windows 为 `Tbox_<四段版本>_win-x64.msix`。
- 公开仓库只提交下载说明、发行说明、必要许可及依赖源码材料，不推送应用源码历史、本机设置或任何签名私钥。
- 在草稿中上传两平台已验收的安装包、SHA-256 和说明，确认资产完全就绪后再正式发布。旧版本不可覆盖。
- macOS 目前使用持久本地开发证书，尚未完成 Developer ID 签名和公证；Windows 已使用固定的持久开发证书，首次安装需信任配套公钥证书，旧用户设备升级仍待验收。当前配置不能据此宣称已实现公开环境的无提示安装。

2026-11-08 按用户要求关闭源码仓库的 GitHub Actions，Release 事件不再触发自动构建或上传。客户端仍从公开 Releases 检查和下载更新，已发布版本继续可用；后续手动发布仍遵循上述资产与验收约定。停用状态和原流程见 [发布流程说明](automatic-releases.md)。停用前的 [首次正式流程](https://github.com/xsddpx/Tbox/actions/runs/42407512233) 已成功：两平台签名、运行检查、完整资产校验及公开发布全部通过，自动生成的发布记录包含实际时间与哈希。

## 验证范围

当前证据见 [1.1.15 首发验收](releases/v1.1.15-verification.md)。两平台 CI 通过 95 项核心、111 项桌面、38 项发布检查，Mac 另有 7 项面板归属回归；Windows 在干净构建环境验证八次真实打开/保存导航和文件名保持。Mac 在线升级、取消重试与升级后授权，以及旧 Windows 设备升级仍待验收，不能用匿名下载或 CI 新装结果替代。

早期 1.1.7 验证记录：测试覆盖：稳定版本选择、禁止降级、未完成发布、匿名请求、重定向域名、损坏与截断下载、取消清理、安装前重复哈希、ZIP 路径与链接、MSIX 身份/版本/架构。93 项桌面测试、95 项核心测试及 Windows 目标编译通过。1.1.7 Mac 开发包完成独立启动、OCR/裁剪、实际媒体解码/导出及真实 ZIP 路径策略验证；已覆盖安装。通过实际窗口的“检查更新”匿名访问公开 Releases，显示“当前没有可用的新正式版本。”，无登录提示；屏幕权限及 3024×1964 取帧仍有效。[本轮双平台 CI](https://github.com/xsddpx/Tbox/actions/runs/42386056953) 已全部通过（应用源码提交 `a68505f`），包括 Windows MSIX 打包/解包、包策略和两平台媒体验证。Windows CI 使用未签名校验包，不代表原电脑的签名与覆盖安装验收。真实公开新旧版本端到端升级仍待发布验收。

API 行为按 GitHub 官方文档实现：[Releases](https://docs.github.com/en/rest/releases/releases)、[Release assets](https://docs.github.com/en/rest/releases/assets)。公开资源支持无认证请求，二进制资产响应可能直接返回内容或重定向到下载地址。
