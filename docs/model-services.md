# 大模型公共能力

## 边界与接入

本功能是应用底座，本身不包含翻译业务、OCR 联动、聊天、MCP 或自主 Agent。现有 OCR 保持离线。工具依赖 `Tbox.Core.ModelServices.ITextModelService`，提交消息和可选模型引用，不接触密钥或提供商 HTTP 数据结构；用户后续新增的独立[翻译工具](translation.md)复用此接口。

设置 → **模型服务** 可以维护多个连接。首版仅实现 **OpenAI 兼容 Chat Completions**，不将 Responses、Anthropic、Gemini 原生接口冒充为兼容协议；本机模型服务可使用其 OpenAI 兼容端点。API 地址应为基础地址（如 `https://api.example.com/v1`），页面显示实际 `/chat/completions` 请求地址。远程必须使用 HTTPS，本机回环地址可使用 HTTP。

1.1.57 按用户最新要求移除“更多设置”：所有可配置项直接显示，不使用折叠。首次默认 DeepSeek，地址和模型预填，日常只需填密钥、保存；首个无默认模型的连接默认勾选全局默认，后续连接不抢占默认。既有连接数据不迁移或删除。测试区取消标题及说明段落，只保留按钮和简短结果；必要的凭据、费用及填写说明放在一个可悬停/点击的说明图标中。

每个连接支持多个模型 ID，每行一个；保存连接后可获取列表，失败可以手动填写。获取到模型并不等于它有调用权限或支持推理。一个“连接 + 模型”组合可设为全局默认，调用方也可显式指定；无默认时不能猜测或自动切换其他服务。

## 密钥

macOS 使用系统钥匙串，Windows 使用用户凭据管理器。`model-services.json` 放在用户应用配置目录，与普通桌面设置分开，只包含非敏感连接信息和随机凭据引用。密钥不进入该文件、日志、提示词或版本库，不支持明文回退。不要把密钥放进 URL。

保存后界面仅显示遮挡占位和“已保存”，不读取密钥回填。打开设置只查询凭据是否存在，不读取密钥数据。替换时输入新密钥，保存成功后清空输入；取消保留旧密钥。删除需确认，删除连接同时删除它的当前凭据；删除失败必须反馈。切换页面或隐藏窗口清除输入框及测试文本。系统凭据库仍可能在实际读写时请求解锁或访问许可。

替换使用新随机凭据引用：新密钥写入成功且配置原子保存成功后才切换引用，配置失败不破坏旧密钥。旧凭据清理失败只记录固定脱敏提示，可能留下不再引用的系统凭据，不伪称它已删除。API 域名或端口变更必须替换/删除旧密钥，防止误发。无密钥连接要明确勾选；不发送之前保存的授权头。不自动跟随任何重定向，不跨域传递密钥，不放宽 TLS 证书校验。

这是本机凭据保护，不承诺抵御已控制当前用户会话的恶意程序。请求期间密钥需进入进程内存。建议使用独立、限额、可撤销的 API Key。

## 调用与状态

保存不发请求；“测试调用”只在点击后发送固定的 `Reply with OK.`，最多请求 32 输出 token，可能产生服务商费用。软件启动、窗口打开及列表获取都不会自动生成内容。没有用户提供的 API 配置或付费许可时，开发测试使用模拟 HTTP 响应，不进行真实付费调用。

测试状态与保存状态独立，修改配置后清除旧测试结果，保存后仍为未测试。只在本次文本流正常结束时标记通过；达到输出上限、内容受限、取消、中断和异常不能当作成功。通过只证明所选模型本次文本请求可用，不推断视觉/音频能力或以后一定可用。

统一接口支持流式文本片段、结束原因、服务返回的 token 用量（不返回则未知）、超时、取消和分类错误。默认全程超时 120 秒，文本生成最多同时 3 个。无自动重试、无自动跨服务回退；遇到工具调用不执行并报错。消息与配置按请求快照，输入最多 100 条/10 万字符，输出最多 10 万字符，响应有字节/行长度限制。工具应自行保留已收到片段并标记取消或失败后的部分结果，不能把任意结束原因都当成功。
