## 模型服务与翻译

- 设置新增「模型服务」，可保存多个 OpenAI 兼容连接和模型，并指定一个全局默认模型。首次打开预选 DeepSeek，地址为 `https://api.deepseek.com`，模型为 `deepseek-chat`；填写密钥并保存后即可作为第一个默认模型。保存不会自动测试。
- 连接、名称、地址、密钥、模型 ID 和默认选择直接显示。费用、凭据和填写说明集中在说明图标中，悬停或点击可查看。
- 密钥保存在系统凭据库：Mac 使用钥匙串，Windows 使用用户凭据管理器。普通配置只保存凭据引用。保存后显示遮挡占位和「已保存」，可替换或确认后删除，界面不回显密钥。
- 「工具」新增「翻译」。可输入或主动粘贴原文，在简体中文、繁体中文、英语、日语、韩语、法语、德语和西班牙语中选择目标语言，对照查看逐步出现的译文，并可停止或复制。打开页面、更改语言或模型都不会自动发送。默认跟随全局模型，也可仅在当次翻译中改用其他已保存模型。

支持 Windows 11 x64 与 macOS 14 及以上 Apple Silicon。安装包继续使用既有持久开发签名。Windows 首次安装可能需要信任现有公钥证书，Mac 安装包尚未经过 Apple 公证。安装步骤见发布正文的安装说明。第三方许可随安装包提供，对应源码由发布正文链接。

同一功能已在 Apple Silicon Mac 的 1.1.55、1.1.56、1.1.57 签名开发包上，沿用原签名并覆盖升级后检查：钥匙串可保存、读取、替换和删除测试凭据；翻译经公共模型能力完成离线调用；正常启动后保留原有屏幕录制授权，并取得 3024×1964 画面。自动化为 130 项核心、233 项桌面、45 项发布检查，Windows 目标可以编译。正式安装包由发布流程构建、签名并做运行检查后公开。

Windows 用户设备上的模型服务、系统凭据、翻译和覆盖升级仍待验收。尚未用真实付费接口验证翻译质量或连接测试。真实系统剪贴板，以及用户已保存密钥在后续版本间是否仍可使用，仍待单独验收。翻译只处理文字，不读取截图，也不连接离线 OCR，不保留翻译历史。
