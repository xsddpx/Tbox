# Tbox 1.1.43

- 点击「安装并重启」或「打开安装程序」时，如果有未结束的工作，弹窗会指出拦截原因。隐藏贴图会提示当前的显隐快捷键。处理完可直接使用已下载的安装包重试。
- 截图和贴图的十项标注工具改用紧凑单排。线宽、字号等属性也横向排列，优先在主条下方显示，空间不足时移到上方。更多菜单收纳低频动作。
- 包含此前的快捷键响应优化，缩短截图界面显示前的等待，并减少复制和贴图中的图像转换。

Mac 开发包复用原签名，解包后在本机通过屏幕采集、OCR 和工具栏原生检查。Windows 签名开发包已在一次性测试机安装并通过屏幕采集、OCR、工具栏和静音录屏检查。当前 Mac 的覆盖升级、用户 Windows 设备验收及公开发布仍待完成。[Windows 验证](https://github.com/xsddpx/Tbox/actions/runs/42838266258)
