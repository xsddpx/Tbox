## 系统要求与运行时

- 两平台安装包内置 .NET 10 LTS，安装 Tbox 时无需另装 .NET。
- Mac 需要 macOS 26 或以上版本和 Apple 芯片。仍在使用 macOS 14 或 15 的用户可下载 [Tbox 1.1.109](https://github.com/xsddpx/Tbox/releases/tag/v1.1.109)。
- Windows 最低要求 Windows 11 x64（build 22000）。项目和 MSIX 采用相同的最低系统版本。
- Mac 在线升级会读取新包的最低系统版本。系统版本不足时，安装前提示先升级 macOS，并保留现有安装。
