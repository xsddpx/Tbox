# Tbox 1.1.19

## 发布与更新

- Windows 与 Mac 安装包改为直接发布在 `xsddpx/Tbox` 的同一 Release，不再把普通下载入口拆到另一个仓库。
- 应用内更新改为匿名读取 `xsddpx/Tbox` 的公开 Release。
- Release 正文首先列出 Windows MSIX 与 Apple Silicon Mac ZIP，并明确 GitHub 自动生成的两个 Source code 压缩包不是安装包。
- 新版本标签或显式手动发布任务会先创建草稿，完整上传并核对所有附件后才公开。

## 安装文件

- Windows 11 x64：`Tbox_1.1.19.0_win-x64.msix`
- macOS 14+ Apple Silicon：`Tbox_1.1.19_osx-arm64.zip`

## 验证范围

本版本用于单仓库迁移和安装验收，尚未作为新的公开正式版本发布。[双平台检查](https://github.com/xsddpx/Tbox/actions/runs/42441457863) 与 [PR #10 复验](https://github.com/xsddpx/Tbox/actions/runs/42441802777) 全部通过。[签名 Windows 安装验收](https://github.com/xsddpx/Tbox/actions/runs/42442202535) 生成 `Tbox_1.1.19.0_win-x64.msix`，SHA-256 为 `87E800F586DED06A9414895C33387291BBE610B57E46F0D585B236D4E4D44868`；云端和当前 Windows 均完成签名安装、OCR、像素裁剪、界面、实际取帧、静音录屏及 GIF/WebP/MP4 保存。当前电脑识别 2 个显示器；系统声音未测试。GitHub 固定显示的 `Source code (zip)` 与 `Source code (tar.gz)` 无法隐藏，也不能直接安装。
