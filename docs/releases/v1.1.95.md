## 贴图、文件夹跳转与长截图

- 贴图滚轮按 5 个百分点的档位缩放，并以指针所在位置为锚点。中键或右键菜单可以恢复当前可见部分的原尺寸。超出屏幕时等比适配，左上角短暂显示实际比例。
- Windows 文件夹跳转栏更及时地跟随系统对话框移动。空间暂时不足时收起，重新出现时保留搜索状态。
- 长截图用限尺寸的实时预览减少内存分配。在已捕获范围内滚动时只更新视口框，保存和复制继续使用完整像素。

三项改动已通过 Windows 试用版用户验收。跨不同 DPI 显示器的专项跟随延迟及 macOS 实机体验待继续验证。

支持 Windows 11 x64 和 macOS 14 及以上 Apple Silicon。安装与校验见发布页。
