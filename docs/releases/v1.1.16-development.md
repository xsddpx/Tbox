# 1.1.16 开发修复记录

公开版仍为 [1.1.15](https://github.com/xsddpx/Tbox-releases/releases/tag/v1.1.15)。本记录不代表 1.1.16 已交付；本机安装版仍为 1.1.13。

## 本轮修复

- 再次发起 OCR 时恢复已最小化的唯一结果窗口，保留按来源决定的置顶行为。
- 展开原图时占用可用内容高度的 35%，其余空间供文字编辑；折叠后编辑器恢复全部可用高度。
- 从截图、贴图和图片预览携带来源中心、工作区与桌面缩放；结果窗口保留用户尺寸、包含系统边框并限制在来源工作区。截图关闭前保存定位数据，避免来源句柄失效；不混用 Retina 图像像素和桌面坐标。
- 新增共用控件回归覆盖三种窗口尺寸、控件不越界、单窗口复用、迟到结果隔离、关闭取消与复制编辑后的全文。
- 两端 OCR 保留行与词的位置及原图尺寸，统一使用左上角归一化坐标；结果只存在当前窗口内存，重识别或关闭时释放。安装包运行诊断现检查这些字段，缺失时阻止通过。
