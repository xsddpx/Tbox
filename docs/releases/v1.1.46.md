# Tbox 1.1.46

- 截图和贴图采用紧凑的单排标注工具栏。选中工具后展开横向属性，空间充足时显示在主栏下方。长截图、录屏和重做归入更多菜单。
- 缩短截图界面的唤起等待，减少复制截图和贴图时的图像转换。
- 在「关于」页点击安装后，Tbox 直接验证安装包和应用身份。验证通过后结束当前任务并退出。Mac 安装完成后自动重启，Windows 由系统安装程序完成升级。
- 修复 Mac 打开主窗口时，文件夹跳转栏检查窗口可能导致闪退的问题。

支持 Windows 11 x64 和 macOS 14 或以上的 Apple Silicon Mac。两个安装包沿用持久开发签名。Windows 首次安装可能需要信任随附的公钥证书，Mac 安装包尚未公证。安装与权限步骤见随附的 `INSTALL.md`。

Mac 主窗口、文件夹选择器和屏幕取帧已在 1.1.45 开发包上实机验证。Windows 的截图、系统 OCR、工具栏和静音录屏已在签名开发包上验证。正式包随发布流程完成构建、签名和运行检查。

第三方许可随安装包提供，对应源码及构建材料见 Release 附件 `Tbox_third-party-sources.tar.gz`。
