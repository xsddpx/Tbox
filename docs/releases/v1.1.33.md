# Tbox 1.1.33

此版汇总上次公开发布后的桌面改进，适用于 Windows 11 x64 和 macOS 14 及以上 Apple Silicon。

- 截图、文件夹跳转、通用和关于集中到一个主窗口。截图、贴图和文件夹跳转的全局快捷键可以在应用内修改。
- 普通截图保留主窗口，可以截取当前页面。Mac 的截图操作提示避开刘海。选中贴图后按空格可展开完整标注工具条。
- 修复 Mac 文件夹跳转。系统打开、保存和文件夹选择面板可跳到访达目录，能区分同名目录并保留保存文件名。

## 验证范围

同一功能代码已在 Apple Silicon Mac 上验证截图、贴图、OCR、长截图、录屏及系统声音，以及三个系统文件面板的跳转。Windows 与 macOS 安装包由正式发布流程签名并验证。混合缩放多显示器、重新登录后的开机启动及用户设备上的在线覆盖升级仍需进一步验收。

## 安装

请按平台下载 Release 顶部列出的安装包并阅读附件 INSTALL.md。包使用持久开发证书，Mac 未经过 Apple 公证，Windows 首次安装可能需要信任随附的公钥证书。依赖许可和对应源码见附带的第三方源码归档。
