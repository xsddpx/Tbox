## Mac 合盖保持唤醒

修复 Mac 安装包的后台组件权限。安装包现在会检查合盖后台组件及其注册文件的权限。

如果覆盖安装后合盖开关仍弹回关闭，可在「系统设置 → 通用 → 登录项与扩展」关闭再开启 Tbox 的后台活动，按 macOS 提示授权，然后回到 Tbox 开启合盖保持唤醒。

Mac 签名候选版已验证覆盖安装保留屏幕录制权限。重新加载后台项后，合盖开关能开启，关闭或正常退出会恢复系统睡眠设置，重新启动后会按保存状态恢复开关。本轮实机验证覆盖电源设置，物理合盖未复测。Windows 功能本版无变更。

支持 Windows 11 x64 或搭载 Apple 芯片的 macOS 26 及以上版本。安装包沿用原签名身份。Windows 首次安装可能需要信任发布正文链接的证书。Mac 使用持久开发签名，尚无 Apple 公证。第三方许可证随包提供，对应源码见发布正文。
