## 截图历史切换

- 图片预览窗口新增左右切换历史截图：页头右侧显示“上一张”“当前 / 总数”“下一张”。
- 键盘 `←` 或 `,` 切到更早一张，`→` 或 `.` 切到更新一张；`Home` 跳到最早，`End` 跳到最新；鼠标滚轮同样可以前后翻阅。
- 首尾循环，连续按键可以一直浏览；切换在原窗口内完成，不改变窗口尺寸与位置，也不重复打开新窗口。
- 只有一张截图时两个按钮禁用且不显示计数；图片已被缓存清理时保留当前画面，并在底部说明原因。
- 切换后“识别文字”“贴图”“保存”“复制”都作用于当前显示的那一张。
