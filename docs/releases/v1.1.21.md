# Tbox 1.1.21

## 托盘轻面板

- Tbox 启动后不再弹出窗口，只驻留 Windows 托盘或 Mac 菜单栏。
- 单击托盘 / 菜单栏图标，在图标旁弹出轻面板：截图、贴图、录屏三块主工具，以及长截图、识别图片文字、显隐全部贴图和文件夹跳转开关。面板失焦、按 Esc 或开始任何工具时自动收起，截图里不会出现面板。
- 面板下方显示最近 4 张截图，悬停即可贴到屏幕或复制，不会另存副本。
- 右键（Mac 也可 Control 单击）图标仍打开原生菜单。重复启动应用或在 Mac 上重新打开 Tbox，同样只打开面板。
- 面板的“长截图”和“录屏”先显示对应颜色的选区，确认后再开始。
- 缺少屏幕录制权限时，只在尝试截图后于面板中显示授权提示。

## 设置

- 设置改为独立窗口，从面板右上角齿轮打开，用「常规 / 文件夹跳转」两个标签切换；截图、贴图、OCR 等日常工具不再放在设置里。
- 强调色改为应用图标的紫晶色，浅色和深色主题同步调整。

## 安装文件

- Windows 11 x64：`Tbox_1.1.21.0_win-x64.msix`
- macOS 14+ Apple Silicon：`Tbox_1.1.21_osx-arm64.zip`

已安装 1.1.16 及以后版本的用户可以在“设置 → 常规 → 检查更新”自动升级。当前安装包使用持久开发证书；Mac 尚未经过 Apple Developer ID 公证，Windows 首次安装可能需要信任随附公钥证书。请先阅读附件 INSTALL.md。GitHub 固定显示的 `Source code (zip)` 与 `Source code (tar.gz)` 不是安装包。
