## 截图与贴图

- 截图、贴图、长截图和录屏的工具栏统一与图像或选区的右缘对齐，下方放不下时会移到上方。
- 长截图和录屏期间保留主窗口原有的显示状态。
- 文字标注靠近右边或底部时会移入图内，并按可用宽度换行。预览、复制和保存使用同样的排版，文字放不下时会提示调整并保留草稿。

## 录屏回放

- 暂停或播放结束后仍可拖动播放头，截取手柄会更新范围并定位画面。标题、播放时间和截取范围统一显示到 0.1 秒。
- 简化时间轴，六宫格缩略图完整显示，选中的取样编号保持高亮。静音录屏收起音量控件。

支持 Windows 11 x64 和 macOS 14 及以上 Apple Silicon。Windows 设备上的截图与录屏交互仍待实机验收。
