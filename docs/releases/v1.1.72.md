## 截图、安装与验证

- 普通截图点「保存」后取消，既不会生成最近截图，也不会写入可编辑历史或更新「上次区域」。保存成功后才记录。
- macOS 本地安装脚本沿用原安装位置。系统和用户的 Applications 目录各有一份 Tbox 时，需要明确指定待升级的路径。
- Windows 的自动化验证覆盖通过 F7 快捷键消息把系统剪贴板中的彩色图片和纯文本创建为贴图。用户设备上的实际按键、托盘右键与在线升级仍待实机验收。

支持 Windows 11 x64 和 macOS 14 及以上 Apple Silicon。两个安装包均使用既有持久开发签名。Mac 安装包尚未经过 Apple 公证。
