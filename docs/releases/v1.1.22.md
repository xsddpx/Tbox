# Tbox 1.1.22

## 全局界面统一

以托盘面板为基准，整个应用改用同一套设计语言。

- 设置窗口：品牌页头加「常规 / 文件夹跳转」分段标签；设置项按「外观与启动 / 截图与贴图 / 截图缓存 / 关于」分组成卡片，每行带图标和说明，快捷键用键帽显示。
- 文字识别、软件更新、图片预览统一页头和操作区；每个窗口只有一个紫晶色主按钮，例如「复制全部」「检查更新」。
- 失败提示改为与托盘面板相同的浮层卡片。
- 全局按钮、下拉框、输入框、开关、复选框、菜单和弹出层统一配色和圆角；开关与选中项使用应用图标的紫晶色。
- 截图、贴图、长截图、录屏控制和录屏回放工具条的字符图标全部换成统一的线性图标；选中的标注工具以紫晶色填充，颜色按钮直接显示当前颜色。
- 任务工具条使用与深色主题一致的深色表面。

功能、快捷键和操作流程不变。

## 安装文件

- Windows 11 x64：`Tbox_1.1.22.0_win-x64.msix`
- macOS 14+ Apple Silicon：`Tbox_1.1.22_osx-arm64.zip`

已安装 1.1.16 及以后版本的用户可以在“设置 → 常规 → 检查更新”自动升级。当前安装包使用持久开发证书；Mac 尚未经过 Apple Developer ID 公证，Windows 首次安装可能需要信任随附公钥证书。请先阅读附件 INSTALL.md。GitHub 固定显示的 `Source code (zip)` 与 `Source code (tar.gz)` 不是安装包。
