## 剪贴板图片

- 修复复制图片后，Windows 剪贴板历史（`Win+V`）和表情符号面板的剪贴板缩略图显示为纯黑的问题。
- Windows 复制改为由平台层发布标准 32 位 DIB 与 `PNG`、`image/png`，不再发布框架生成的单色位图格式；画图、Office、聊天工具和系统剪贴板历史读到的都是原始彩色画面。
- 复制内容仍独立于截图、贴图和结果窗口的生命周期，关闭来源窗口或结束进程后其他应用依旧可以粘贴。

支持 Windows 11 x64 与 macOS 14 及以上 Apple Silicon。安装包继续使用既有持久开发签名。Windows 首次安装可能需要信任现有公钥证书，Mac 安装包尚未经过 Apple 公证。安装步骤见发布正文的安装说明。第三方许可随安装包提供，对应源码由发布正文链接。

自动化为 134 项核心、233 项桌面检查，Windows 目标可以编译并生成安装包。新增的真实桌面剪贴板检查在打包流程中运行：复制 8×6 测试图后校验格式、尺寸，并用系统剪贴板接口读回像素。剪贴板检查需要已解锁的桌面，锁定状态下会明确失败而不是静默通过。

Windows 用户设备上的覆盖升级与真实跨应用粘贴仍待验收。
