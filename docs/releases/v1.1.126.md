## 窗口置顶

在「工具 → 窗口置顶」启用，支持自定义快捷键、紫色边框、同时置顶多个窗口及逐项解除。

- Windows 按 `Win+Ctrl+T` 置顶当前窗口，再按一次解除。解除后，从属浮窗恢复各自原有的置顶状态。
- Mac 按 `Control+Shift+T` 为当前窗口创建实时浮窗，点击浮窗回到来源窗口。首次使用可在设置页授权屏幕录制和辅助功能。

两平台均通过自动化测试。Windows 在签名候选版的 Windows 11 虚拟机中验证了资源管理器和终端同时置顶、快捷键单独解除、最小化恢复和关闭来源后清理。Mac 签名候选版已验证覆盖升级后保留屏幕录制权限。Windows 跨屏缩放、Mac 全局快捷键和实时浮窗仍待实机验收。

系统要求为 Windows 11 x64 或搭载 Apple 芯片的 macOS 26 及以上版本。安装包沿用原签名身份。Windows 首次安装可能需要信任发布正文链接的证书。Mac 使用持久开发签名，尚无 Apple 公证。第三方许可证随包提供，对应源码见发布正文。
