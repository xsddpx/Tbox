# Tbox 1.1.20

## 新图标

- 软件图标改为紫晶工具盒：深色圆角底座上的紫色立方体，侧面印白色 T。Windows 开始菜单、任务栏、托盘、安装包，以及 Mac Dock、Finder 和主面板使用同一图标。
- Mac 菜单栏使用镂空 T 的立方体剪影，跟随系统深浅色着色。

## 界面

- 主面板简化为单列工具入口：开始截图、剪贴板贴图、文字识别、文件夹跳转，以及显隐贴图和区域录屏，设置单独放在右上角。
- 文字识别宽窗口左右对照原图和文字，窄窗口默认收起原图，可以展开；切换布局不丢失已编辑的文字。

## 发布与更新

- Windows 与 Mac 安装包直接发布在 `xsddpx/Tbox` 的 Release，应用内更新匿名读取同一仓库。
- 已安装 1.1.15 及更早版本的用户需要从本页手动安装一次 1.1.20，之后可以在“常规 → 检查更新”自动升级。

## 安装文件

- Windows 11 x64：`Tbox_1.1.20.0_win-x64.msix`
- macOS 14+ Apple Silicon：`Tbox_1.1.20_osx-arm64.zip`

当前安装包使用持久开发证书；Mac 尚未经过 Apple Developer ID 公证，Windows 首次安装可能需要信任随附公钥证书。请先阅读附件 INSTALL.md。GitHub 固定显示的 `Source code (zip)` 与 `Source code (tar.gz)` 不是安装包。
