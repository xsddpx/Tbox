# Tbox 1.1.34

此版精简旧工程和过时设计材料，并修正 Windows 开始菜单、任务栏与托盘中的 Tbox 图标偏小问题。

- 两平台只保留共用的 Avalonia 桌面工程；删除已经被取代的旧 WinUI 工程、旧打包入口、旧集成压测和 UI 1.0 HTML 原型。
- UI 3.0 五张现行规范板集中到 `docs/images`，README、架构、验收、安装和更新说明同步到当前单一主窗口与共用工程。
- Windows 安装包补齐 Shell 无底板目标尺寸资源，避免系统再次缩小图形或添加额外底板；EXE 多尺寸图标同步收紧透明边缘。

## 验证范围

[双平台检查与 Windows 签名安装工作流](https://github.com/xsddpx/Tbox/actions/runs/42763581032)已通过。Windows 1.1.34 在干净机器和当前电脑完成签名覆盖安装，并通过身份、文字识别、像素裁剪、共用窗口渲染、实际取帧与录屏检查。

## 安装

请下载 Windows MSIX 或 macOS ZIP，并阅读附件 INSTALL.md。Windows 覆盖安装保留包身份、设置和缓存。
