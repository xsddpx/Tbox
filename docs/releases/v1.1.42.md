# Tbox 1.1.42 · B 紧凑单排工具栏

状态：实现与安装验收中，尚未公开发布，不代表两平台实机均已通过。

Windows 签名包与双平台 CI 已通过，本机已从 1.1.41 覆盖安装，工具条、系统 OCR 和双屏采集通过。PR #35 已合并至 `0d11341`，应用源码与安装包所用版本一致。本机额外录屏检查受锁屏阻塞，仍需解锁后复验；Mac 实机尚未验收，不能因合并而标记全部验收完成。

- 截图、贴图改为紧凑单排主条，保留完整十项标注和输出动作。
- 截图的长截图、录屏、重做归入“更多”；贴图的“更多”只提供重做。
- 属性也改为横向单排，随工具显示色点和线宽、字号、序号大小等当前值；优先下置，底部空间不足时上移，间隔保持 6 个逻辑单位。
- Esc 先收起属性或更多，不误取消当前工具；从属性返回画布后第一笔可直接绘制。
- 复制动作使用中性强调，紫色继续表示选中的标注工具。

Windows 安装版验证增加截图属性下置/上移、参数更新、Esc 层级、更多菜单及贴图原生属性浮层检查；只保存工具条本身的渲染图，不额外保存用户桌面画面。
