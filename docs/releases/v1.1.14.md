# Tbox 1.1.14

首个公开下载的跨平台版本，支持 Windows 11 x64 和 macOS 14+ Apple Silicon。

- Windows 与 Mac 共用界面和交互，移除搜索，使用新的白色透明倒品字图标。
- 提供区域截图、标注、贴图、中英文离线 OCR，以及区域录屏和 GIF、WebP、MP4 保存。
- 在“常规 → 检查更新”匿名检查、下载并确认安装后续版本，无需 GitHub 账号。
- 使用持久签名身份，Mac 升级保持安装位置，尽量保留已有权限。

截图、OCR、贴图及录屏已有平台运行验证；Windows 还完成实际安装和标准打开、保存面板的目录跳转检查。

本次先发布当前可用版本，完整迁移仍在继续：Mac 文件夹跳转与长截图的完整实机交互、Windows 系统声音、混合缩放多显示器、开机启动重新登录及旧 Windows 用户设备升级仍待进一步验收。Mac 文件夹跳转暂按实验功能使用，识别不到系统面板时会停止操作。应用内在线更新的首次公开下载链路将在发布后继续验证。

当前安装包使用持久开发证书；Mac 尚未经过 Apple Developer ID 公证，Windows 首次安装可能需要信任随附公钥证书。请先阅读附件 INSTALL.md。Intel Mac 暂无安装包。
