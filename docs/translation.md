# 翻译工具

翻译是大模型公共能力的首个独立消费者，不把翻译规则放进公共模型层。入口为主窗口侧栏“工具 → 翻译”。

## 使用

1. 在“模型服务”配置连接。首次界面预选 DeepSeek 并填写官方地址 `https://api.deepseek.com` 和 `deepseek-chat`；填写密钥、保存即可作为首个默认模型。不会自动发送测试。1.1.57 按用户要求取消“更多设置”，地址、模型 ID、多连接和默认选择直接显示，必要说明集中在说明图标中。
2. 进入翻译，输入文字或主动点击“粘贴文字”，选择目标语言。默认跟随全局模型，也可仅在当前运行中为翻译指定已有模型。
3. 确认页面显示的服务地址，点击“翻译”后才发送原文。模型调用可能产生服务商费用。
4. 译文逐步显示，可停止或复制。截断、取消、中断和失败会保留部分译文并明确说明；不会自动续写、重试或切换模型。

原文最多 20000 字符，输出最多请求 4096 token。模型负责判断源语言，支持八种目标语言。输入已经是目标语言时不切换备用语言。译文排版由模型尽量保留，不保证像素级还原。

## 状态与隐私

- 打开页面、改语言、改模型和粘贴都不会自动调用 API。不会在后台读取剪贴板。
- 显示原文与只读译文，内容宽度至少 480 时左右对照，否则上下排列；两个编辑区域自行滚动，主窗口可纵向滚动，不缩小按钮来适配窄屏。
- 生成中只读原文并锁定选项，按钮改为“停止生成”。切换页面或隐藏窗口同样停止；旧请求即使忽略取消也不能覆盖新结果。
- 只有正常结束且非空才标记完成；其他结束原因和无结束标记不能当成功。服务未返回用量时显示未知，不估算费用。
- 修改输入或选项会清除旧译文，避免复制与新原文不对应的结果。可以复制已停止/失败后的部分内容，但反馈明确标为部分。
- 当前原文和译文只保留在内存中，切页或隐藏可保留当前内容，退出丢弃。不写历史、日志或缓存；没有图片上传、截图翻译或 OCR 联动。
- 工具只引用 `ITextModelService`，不接触凭据存储或 HTTP。模型设置的密钥安全和错误分类继续复用公共层。

## 参考与适配

2026-11-11 查阅 [PixPin 翻译官方入口](https://pixpin.cn/docs/other/translate)（当前页面导向截图翻译产品展示），采用原文/译文对照、目标语言和复制译文的短流程。证据为官方文字及页面示意，不是客户端实测，页面版本未知。Listary 的已查阅资料围绕文件工作流，没有本轮可直接采用的翻译流程。Tbox 只实现已确认的文字翻译，不照搬 PixPin 图片回填、朗读、会员和备用语言能力。此前 TEMP 原型作为布局参考，不代替当前共用控件和安装版验收。

## 验证

自动测试使用假公共能力和进程内模拟 HTTP，不使用对话中提供的密钥、不产生真实 API 费用。覆盖正常/部分结果、取消、迟到响应、输入边界、模型选择、明确粘贴/复制，以及 680/800/1280 窗口布局。安装版可显式运行 `--smoke-test <TEMP 目录> --verify-translation`，通过真实公共服务和模拟 HTTP 验证工具整条调用链；此验证不等于真实提供商的翻译质量测试。
